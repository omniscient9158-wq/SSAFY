## 이번 검증 기록

- 2026-10-21 Codex 인앱 브라우저에서 `http://localhost:8501/` 화면을 확인했다. 검색 범위 안내를 열어 읽었고, A-454의 예시 질문을 입력창에 채운 뒤 로컬 검색에서 외부 근거 1건이 표시되는 것을 확인했다. 벡터·LLM API는 호출하지 않았다.
- 브라우저에서 확인한 검색 안내는 선택 ID에 연결된 승인 발췌만 검색한다는 점, 로컬 단어 일치와 벡터 의미 검색의 차이, 검색 결과 없음의 해석, 수치 조건 검색과 단일 화합물 문헌 질의의 구분을 설명한다. 제출용 스크린샷 파일은 아직 프로젝트에 저장하지 않았다.
- API를 호출하지 않는 로컬 검증으로 AqSolDB 9,982행의 분할 수와 고유 ID, 메타데이터 텍스트 필드 일부, 조건 검색 결과를 확인했다. 조건 검색 예시는 Train 3,175건이며 반환한 50개 레코드가 두 조건을 모두 만족했다.
- 외부 문서 컬렉션은 기존 승인 자료 3건(3청크)에 라이선스·화합물 식별 대조를 마친 2-methylpyridine 보조 문서 1건을 추가해 총 4청크다. 메타데이터는 출처 균형 train 표본 100건을 색인했으며 동일 명령 재실행에서 신규 0 / 총 100으로 멱등성을 확인했다.
- 2026-10-21 리뷰 피드백에 따라 `aspirin` 별칭을 AqSolDB E-1274 `acetylsalicylic_acid`로 연결하도록 코드를 수정했다. 로컬 CSV에서 실험 LogS -1.72를 확인했다. 결과 카드에는 측정값과 예측값, 해당 레코드의 절대 오차를 함께 보여주도록 했다. 다만 이번 변경 뒤 브라우저에서 버튼을 실행해 보지는 못했으므로 체크 항목은 미확인으로 유지한다.
- 고급 설정 안에 문헌 검색 방식을 넣고 GMS 의미 검색의 크레딧 사용 안내를 명확히 했다. 로컬 서버 포트 8501은 점유되어 있었고 8503 시도는 브라우저와 HTTP 요청에서 응답을 받지 못해 중단했다. 변경된 UI 화면 및 제출용 스크린샷은 다음 브라우저 실행 때 확인·저장해야 한다.
