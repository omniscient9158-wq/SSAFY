# 2회차 셀프·상호 체크리스트 대조 결과

> 원본 `docs/reference/2회차_셀프·상호_체크리스트.pdf`의 1~27번 항목과 현재 코드·문서·이번 로컬 검증 결과를 대조한 진행표입니다. 체크리스트 기준에 따라 직접 확인하지 않은 항목은 통과로 처리하지 않았습니다. 브라우저에서 확인하지 않은 항목과 상호 점검은 남아 있습니다.

## 현재 집계

집계는 개별 기능의 실행 점검 결과다. 문서 확보 대상 100종과 실제 문헌 답변 범위 6종을 구분하며 종합 완료는 보류한다. 자세한 범위는 `03_출처_검토_보고서.md`를 따른다.

미확인은 아직 실행 증거가 없다는 뜻입니다. `구현 공백`은 현재 파일에서 요구 기능이 보이지 않는 부분이며, 화면에서 실행해 실패를 확인한 것으로 간주하지 않았습니다.

## 최근 검증 근거

- 이름·별칭과 문서 후보 전체 조회: Train 7,488종 중 단일 Wikidata 항목 연결 6,281종, 위키 문서 후보 2,116종. GMS 없이 조회했고 캐시 재실행도 확인했다. `docs/evidence/wikidata_coverage_summary.json`, `03_출처_검토_보고서.md`에 기록했다. 에탄올·글리세롤·아세톤의 한글 검색과 화합물 목록 선택은 AppTest에서 확인했다. 문서 후보 링크를 승인 문헌 완료로 취급하지 않아 종합 판정은 바꾸지 않았다.
- 문서 연결 대상 100종: data/document_discovery_manifest.csv. 기존 임의 표본의 연결 부족은 docs/evidence/metadata_document_coverage.csv에 보존했다.
- 원문·이용 조건·후보 승인 추적: data/approved_external_sources.csv 및 docs/03_출처_검토_보고서.md. 아스피린 후보와 승인 문서 ID를 연결했다.
- RAG 비교: docs/06_검증_결과.md 및 docs/evidence/의 원본 답변·근거 JSON. 오류가 발견된 카페인 부가 설명은 수정 후 재검증했다.
- F2010 실제 표·인용 화면: screenshots/12_measurement_comparison.png. LogS와 mg/mL 및 측정 조건을 직접 같은 값으로 비교하지 않는다.
- F2012 오류 상태 화면: screenshots/13_missing_key_notice.png, 14_empty_index_notice.png. 문헌 답변 화면은 15_aspirin_answer.png다.
- 외부 요청 정책: docs/evidence/external_request_policy_check.json. 실제 PubChem 응답과 제어된 간격·Retry-After 검사를 구분해 기록했다.
- 수치 조건 추가 점검: 정상 조건의 3,175개 일치 건수를 확인했다. 지원하지 않는 조건, 쉼표 없는 다중 속성, OR, 역전 범위와 무한대 경계는 잘못 적용하지 않고 안내한다.

## 남은 일

후속으로 [인용 있는 후보 16종 검토](03_출처_검토_보고서.md)를 작성했다. 저장 본문의 질문 적합성을 항목별로 대조하고 일부 NOAA 원문을 확인했다. D-1360은 hydroxy/amino 이름 불일치가 발견되어 정체성 확인 전 승인하지 않는다. 신규 승인·색인은 0건이고 종합 미확인 판정은 유지한다. 원문 전체 검토 완료와 저장 본문 검토를 구분한다.
