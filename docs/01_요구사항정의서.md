# 분자 수용해도 예측 및 근거 탐색 — 요구사항 정의서 초안

> 초안 상태: 요구사항 정의서 PDF와 셀프·상호 체크리스트에 맞춰 도메인에 적용했다. 구현과 실행 증거가 없는 항목은 완료로 표시하지 않는다. 문서 출처 확보와 이용 조건 확인은 계속 진행한다.

## 1. 프로젝트 개요

- **프로젝트명:** 분자 수용해도 예측 및 근거 탐색: AqSolDB LogS 분석과 원자료 그룹 평가
- **앱 이름:** AqSolDB 수용해도 분석
- **목표:** 선택한 화합물의 메타데이터와 출처 확인 문서를 검색해, 실제 근거를 표시하는 화합물 질의응답(RAG) 서비스를 구현한다. AqSolDB LogS 회귀 분석은 도메인 특화 보조 기능으로 제공한다.
- **핵심 질문:** 선택 화합물과 연결된 AqSolDB 데이터 및 출처 확인 문서를 검색해 답변할 수 있는가? 답변에 사용한 근거만 출처와 함께 표시하고, 확인할 근거가 없으면 추측을 멈추는가?
- **분석 목표:** 회차 요구사항은 분류기나 회귀기 중 어느 하나를 필수로 정하지 않는다. F2010은 도메인에 맞는 기능을 요구하므로, 본 프로젝트는 LogS 회귀를 보조 기능으로 선택했다. 회귀 수치의 설명을 RAG로 뒷받침하고 인용을 함께 제공해야 F2010 수용 기준을 충족한다. 화면의 논문 기반 LogS 구간은 설명용이며 학습된 분류기나 분류 성능을 의미하지 않는다.
- **범위 결정:** 초기 분류 아이디어를 필수 요구사항으로 오해하지 않는다. 3일 프로젝트에서는 프롬프트 기반 검색·문서 선별, 두 컬렉션의 검색·인용, 항목별 질의응답, 자연어 조건 탐색을 우선 완성한다. 분류/GNN은 현재 범위에 포함하지 않는다.
- **사용 범위:** 학습·데이터 분석 목적. 안전·취급·건강 판단은 제공하지 않는다.
- **핵심 데이터:** Harvard Dataverse AqSolDB, 공개 v1, CC0 1.0 표시 확인. 로컬 사본은 train 7,488행 + test 2,494행. 상세 출처와 미러는 README에 기록한다.
- **도메인 조건:** 100개 이상 화합물 메타데이터(실제 로컬 데이터 9,982행). 외부 설명 문서의 문장별 출처·이용 조건은 별도 확인하며 미확정 문서는 제출용 인덱스에 넣지 않는다.

## 2. 사용자 및 대표 질문

사용자는 화합물을 선택하거나 조건 검색으로 후보를 고른 뒤, 화합물 자체의 데이터와 출처 문서를 바탕으로 질문한다.

- 이 화합물의 AqSolDB 실험 LogS와 분자 특성은 무엇인가?
- 이름/구조가 비슷한 화합물의 측정 용해도는 어떻게 다른가?
- 모델 예측과 실험값은 어느 정도 차이가 나는가?
- 특정 분자량·TPSA·LogP 조건을 만족하는 화합물은 무엇인가?
- 외부 문서에서 이 화합물의 설명을 확인할 수 있는가?

## 5. 선택 심화 기능

포트폴리오 측정 항목으로 **F2015 RAG 전후 답변 비교**를 우선 선택한다. 동일 질문 5개 이상에 대해 검색 없는 답변과 근거 검색을 거친 답변을 비교하고, 사실 근거성·인용 정확도·근거가 없을 때의 보류를 기록한다. 이 평가는 필수 RAG 기능을 마친 뒤 진행하며, 실제 검토하지 않은 수치나 향상률을 쓰지 않는다. 시간이 남으면 F2014 MMR과 일반 유사도 검색을 한두 질문으로 비교한다. F2013 직접 UI 구현과 F2016 추가 출처 결합은 현재 우선 범위에서 제외한다.

## 6. 완료 판정 원칙

요구사항은 코드/문서가 존재한다는 사실만으로 통과가 아니다. 체크리스트의 실행 방법대로 직접 결과를 확인하고 증빙을 남겨야 한다. 검증 전 상태는 미확인으로 기록한다. 출처 검증과 기능 검증은 별도 항목으로 관리한다.

## 8. 도메인 및 사용자 흐름

**AqSolDB 수용해도 분석**은 AqSolDB의 실험 수용해도(LogS)와 분자 descriptor를 분석하고, 근거 문서 질의응답과 데이터 기반 예측을 제공하는 분석 서비스다. 사용자는 화합물을 선택해 이름, 구조 표기(SMILES), 실험값, 모델 예측과 오차, 유사 화합물의 측정값, 확인된 외부 문서 링크를 살펴본다. 예측은 실험값과 구분하며, 데이터 범위 밖에서는 신뢰도가 낮을 수 있음을 안내한다.

대표 질문은 다음과 같다.

- 이 화합물의 AqSolDB 실험 LogS와 분자 특성은 무엇인가?
- 구조가 비슷한 화합물끼리 측정 용해도는 어떻게 다른가?
- 모델 예측은 실험값과 얼마나 차이가 나는가?
- 특정 분자량·TPSA·LogP 조건에 맞는 화합물은 무엇인가?
- 출처가 확인된 외부 문서에서 이 화합물의 설명을 찾을 수 있는가?

## 9. 데이터 항목 및 저장 설계

로컬 CSV는 train 7,488행, test 2,494행이며 총 9,982행이다. 식별·구조 열은 `ID`, `Name`, `InChI`, `InChIKey`, `SMILES`; 측정 관련 열은 `Y`, `SD`, 원본 표기 `Ocurrences`, `Group`이다. 분자 descriptor는 `MolWt`, `MolLogP`, `MolMR`, `HeavyAtomCount`, `NumHAcceptors`, `NumHDonors`, `NumHeteroatoms`, `NumRotatableBonds`, `NumValenceElectrons`, `NumAromaticRings`, `NumSaturatedRings`, `NumAliphaticRings`, `RingCount`, `TPSA`, `LabuteASA`, `BalabanJ`, `BertzCT`다. descriptor는 입력 특성이며 각각을 용해도의 원인으로 단정하지 않는다.

화합물 메타데이터와 외부 문서는 서로 다른 컬렉션에 저장한다. 화합물 ID와 원자료 행 식별자를 보존하고, 문서 청크에는 제목·원문 URL/파일과 쪽·제공자·인용·이용 조건·연결된 화합물 ID를 포함한다. 예측 결과를 별도로 저장할 경우 모델 버전과 평가 시각도 남긴다. 여러 원자료의 통합 데이터이므로 `Group`, `SD`, `Ocurrences`와 A-I 출처 코드를 보존한다.

## 10. 분석 기능 및 구현 범위

도메인 특화 기능으로 분자 descriptor 기반 LogS 회귀와 유사 화합물 비교를 제공한다. 평가 시 일반 무작위 분할과 원자료 그룹 단위 holdout을 비교해, 출처 그룹이 달라질 때 오차가 어떻게 달라지는지 관찰한다. 필요하면 구조 scaffold 분할을 추가한다. 모델 평가는 MAE와 RMSE를 중심으로 하고 R²를 보조로 본다. 제공된 test 분할은 모델 선택에 사용하지 않고 최종 평가용으로 남긴다. 모델 설명은 예측 또는 연관성으로 표현하며 인과 주장으로 바꾸지 않는다.

필수 기능 F2001-F2012 구현을 우선한다. 심화 후보는 여러 문서 출처 유형 결합(F2016), MMR(F2014), RAG 전후 품질 비교(F2015)이며, 일정과 필수 기능 완료 후 선택한다. HTML/CSS/JavaScript 직접 UI(F2013)는 별도 심화 항목으로 취급한다.

## 11. 출처 및 데이터 검토 판단

PubChem 표본 점검에서는 300개 중 285개 CID 연결, 179개 설명 텍스트, 정리 후 118개 문장 후보를 확인했다. 표본 300개 중 원출처 인용이 표시된 것은 41개였고, 별도 100개 후보 목록은 PubChem 인용이 있는 26개와 PubChem 기록만 확인된 74개를 구분한다. 이 목록은 후보 조사자료이며 최종 색인 승인 목록이 아니다. 실제 색인할 문서만 원문 출처와 이용 조건을 검토하고 미확정 항목은 보류한다. 상세 기록은 [출처 검토 보고서](03_출처_검토_보고서.md)와 `../research/provenance/`에 둔다.
