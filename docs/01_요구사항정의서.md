# 요구사항 정의서

## 프로젝트와 도메인

- 작성자: 김지은 · 서울 8반 · 1인 프로젝트
- 프로젝트명: AqSolDB 화합물 근거 탐색
- 목표: 화합물 기록과 출처 검토 문헌을 검색해 실제 근거를 인용하는 질의응답을 제공한다.
- 대상: Train 7,488종 이름 검색, Train 메타데이터 100건 색인. Test 2,494행은 검색·색인에서 제외한다.
- 문헌: NOAA/CAMEO의 NTP·USCG 기록, Wikipedia 등 출처·이용 조건 검토를 마친 14종·17발췌. 현재 벡터 색인에는 기존 6종·9발췌가 있으며, 추가 승인 8종은 임베딩 갱신 대기다. 86종은 미승인 조사 후보다.
- 출처·이용 조건: [출처 검토 보고서](03_출처_검토_보고서.md)와 승인 CSV에 기록한다. AqSolDB 배포본의 CC0 표시를 원자료 전체의 이용 조건으로 확대하지 않는다.
- 사용 범위: 교육용 물성 데이터 탐색. 안전·취급·건강 조언은 제공하지 않는다.

## 근거가 필요한 대표 질문

1. 타우린 문헌의 수용해도 값·단위·온도·원출처는 무엇인가?
2. 카페인의 문헌 기록과 AqSolDB LogS는 같은 조건에서 측정됐는가?
3. 안트라센의 외관과 물에서의 거동은 원문에 어떻게 적혀 있는가?
4. 현재 승인 자료로 타우린의 pH별 정량적 변화량을 알 수 있는가?

## 기능 요구사항


| ID | 요구사항 | 도메인 적용 및 수용 기준 | 우선순위 |
|---|---|---|---|
| F2001 | 항목 메타데이터 적재 | 100개 이상 화합물을 읽고, 화합물 1개마다 검색 가능한 단일 메타데이터 텍스트를 만든다. 필수 필드와 원자료 행 ID를 보존하고 로드 건수를 표시한다. | 필수 |
| F2002 | 메타데이터 벡터 색인 | 메타데이터 전용 컬렉션에 임베딩한다. 고정 ID로 upsert해 두 번 실행해도 항목/청크 수가 늘지 않는다. 색인 건수를 화면에서 확인한다. | 필수 |
| F2003 | 검색어 추출 | 화학 정보 전문가 역할 프롬프트가 선택 항목과 질문으로부터 JSON 배열 검색어를 추출한다. 선택 화합물의 고유명/식별자 검색어는 반드시 포함한다. 파싱 실패를 처리한다. | 필수 |
| F2004 | 외부 문서 수집·선별 | 허용한 출처에서 후보를 검색하고 선별 프롬프트로 관련 문서를 선택한다. 선택 화합물 자체를 다루는 문서는 제외 규칙보다 우선한다. 색인·제외 결과와 이유를 기록하고, 같은 검색어는 캐시해 다시 수집하지 않는다. 본문과 URL/파일명·쪽을 보존한다. | 필수 |
| F2005 | 외부 문서 청킹·색인 | 메타데이터 컬렉션과 분리된 문서 컬렉션에 저장한다. 청크마다 제목, 원문 위치, 제공자/유형, 관련 화합물 ID를 보존한다. 청크 크기·중복 길이는 설정으로 바꾸며 ID는 항목 ID:문서 ID:순번을 포함한다. | 필수 |
| F2006 | 근거 검색·병합 | 선택 화합물 메타데이터는 검색 없이 항상 근거에 포함한다. 외부 문서는 선택 화합물 범위에서 질문과 의미 유사도로 검색한다. 두 결과 병합 및 중복 제거를 하고 외부 근거 Top-k는 설정으로 조정한다. | 필수 |
| F2007 | 근거 기반 답변 | LangGraph 그래프를 `retrieve`와 `generate` 두 노드로 구성한다. 생성 프롬프트는 검색된 근거만 사용한다. 근거 유형을 화합물 메타데이터/외부 문서로 구분하고, 근거가 없으면 확인 불가라고 답한다. | 필수 |
| F2008 | 근거 표시 | 주요 주장에 근거 번호를 붙인다. 실제 인용된 근거만 제목·원문 URL 또는 파일명/쪽과 함께 화면에 표시한다. 인용이 없으면 그 상태를 안내한다. | 필수 |
| F2009 | 항목 선택·질의응답 | 목록/검색 결과에서 화합물을 선택하고 채팅한다. 대화 이력은 화합물별로 나뉘어, 다른 화합물로 바꾸면 앞선 문맥이 섞이지 않는다. | 필수 |
| F2010 | 도메인 특화 기능 | 검색된 문헌의 수용해도 기록을 AqSolDB 실험값과 비교하고 근거 번호·발췌·원문 링크를 표시한다. 단위와 측정 조건을 구분한다. LogS 예측과 유사 화합물은 보조 기능으로 제공한다. | 필수 |
| F2011 | 자연어 조건 탐색 | 자연어 조건에서 구조화된 필터를 파싱하고 메타데이터 후보를 조회한다. 실제 수치 조건을 결정적으로 재검사해 조건에 맞는 항목만 표시한다. 결과 선택 시 해당 화합물 대화로 이어진다. | 필수 |
| F2012 | 진행 상태·안내 | 수집/검색/생성의 진행 상태를 표시한다. 색인 없음, API 키 누락, 네트워크/호출 오류를 안전한 메시지로 안내한다. 본 도메인은 건강·금융 자문이 아니므로 전문가 대체 면책은 해당없음으로 판단하되, 안전·취급 조언을 제공하지 않는 범위를 표시한다. | 필수 |

## 선택 심화와 완료 기준

선택 심화는 F2015 RAG 전후 품질 비교다. 동일 모델·고정 질문 5개를 대상으로 사실 정확성·인용·근거 부족 시 보류를 비교했다. F2013 직접 UI·F2014 MMR·F2016 추가 출처 결합은 선택하지 않았다.

이번 제출 자료에는 Train 메타데이터 100건과 승인 문헌 14종·17발췌를 포함한다. 문헌 벡터 색인에는 기존 6종·9발췌가 반영되었고, 추가 승인 8종은 임베딩 사용량 제한으로 갱신 전이다. 나머지 미승인 조사 후보 86종은 서비스의 승인 범위에 포함하지 않는다. 구현 코드의 존재와 실행 검증을 구분하며, 기능별 판정은 [27항목 체크리스트](../체크리스트.pdf), 테스트 결과는 [테스트 결과표](09_테스트_결과표.md)를 따른다.
