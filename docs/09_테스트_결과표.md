## 검증 범위의 한계

- 승인 문헌 데이터는 14종·17발췌다. 의미 검색의 보존 색인은 6종·9발췌다. 나머지 승인 8종은 GMS 임베딩을 시도했으나 사용량 한도로 요청이 거절되어 벡터 검색 검증을 수행하지 못했다. 미승인 조사 후보 86종은 문헌 답변 범위에 포함하지 않는다.

- 새 SMILES 예측의 참고 눈금은 코드에 적용했으나 이번 실제 브라우저 캡처는 타우린 실험값 경로에 한정한다. 이 화면은 대표 실행 경로의 증빙이며 모든 입력 변형을 시각 검증한 결과는 아니다.

모든 생성 답변의 정확성이나 전체 화합물에 대한 문헌 답변 준비 완료를 주장하지 않는다.
