# AqSolDB 화합물 문서 출처 표본 점검

## 목적

AI 코어 프로젝트의 데이터 출처·이용 조건을 기록하기 위해 AqSolDB 표본을 PubChem으로 연결해 문서 후보의 출처 추적 가능성을 살폈다. 체크리스트의 100개 이상 조건은 화합물 메타데이터 항목 수에 해당하며 외부 문서 100건을 요구하는 것으로 읽지 않는다. 이 파일은 원출처·이용 조건 검토가 끝난 최종 승인 목록이 아니다.

## 표본 및 결과

- 입력: `train.csv`와 `test.csv` 전체를 합친 뒤 파일 순서에 따라 일정 간격으로 뽑은 300개 표본
- 데이터 행 수: train 7,488, test 2,494 (총 9,982)
- 정확한 구조 대조 키: AqSolDB `InChIKey`와 PubChem Compound ID(CID)
- 표본에서 CID에 연결: 285 / 300
- PubChem Record Description 텍스트 존재: 179 / 300
- PubChem 설명 항목에 원출처 인용까지 붙은 행: 41 / 300
- 이 CSV에 담은 설명 문장 후보: 100개 (안전·위험 안내, 관계 이동/중복 문구, 40자 미만 문장을 제외)
- 선택한 후보 중 PubChem에 원출처 인용이 표시된 항목: 26 / 100

## AqSolDB 데이터 이용 조건 확인

Harvard Dataverse의 공식 데이터셋 API를 확인했다. 최신 공개 버전은 v1이며 라이선스는 CC0 1.0으로 표시된다. 공식 원본 파일은 `curated-solubility-dataset.tab` (file ID 3407241, 3,844,092 bytes)이다. 프로젝트 폴더의 `train.csv`/`test.csv`는 Hugging Face에 올라온 분할 사본이므로 제출 시 canonical DOI와 논문을 인용하고, 사용한 분할 사본 URL도 README에 함께 기록한다.

## LogS 측정값의 원자료 추적

AqSolDB 논문은 통합 파일의 `ID`가 원본 데이터셋을 표시한다고 설명한다. 따라서 `A-3`처럼 접두어를 분리해 A-I 중 어느 원자료 묶음에 속하는지 연결할 수 있다. 후보 CSV와 audit CSV에 이 접두어, 원자료 이름, 논문 내 참고문헌 번호를 추가했다. 이 정보는 실험 LogS 값의 출처를 추적하는 데 쓰며, PubChem 설명 문장의 원출처와는 별도 provenance다.

- A: eChemPortal/OECD [14]
- B, D: EPI Suite 원자료 [15], [17]
- C: Raevsky et al. [16]
- E: Huuskonen et al. [1]
- F, H: Wang et al. 계열 [8]; H는 Jain–Yalkowsky 자료 정리본 [19]에 기반
- G: Delaney et al. [2]
- I: Goodman Group corrected Solubility Challenge [20]

## 각 행의 출처 추적 필드

새 폴더 구조로 옮긴 뒤 로컬 9,982행을 다시 집계했다. A-I 접두어가 모두 매핑 파일에 존재했고, 미매핑 접두어/행은 0건이었다. 이는 각 행이 AqSolDB 논문 Table 1의 원자료 묶음으로 연결된다는 확인이다. 개별 측정값의 원 논문 원문을 행마다 대조하거나 upstream 자료의 별도 라이선스를 확인한 결과는 아니다.

- AqSolDB ID 및 A-I 접두어로 추적한 원자료 출처 코드, InChIKey, SMILES, 실험 LogS, Harvard Dataverse DOI와 논문 인용
- PubChem CID 및 해당 화합물의 고정 URL
- PubChem Record Description 원문 텍스트
- PubChem이 표시한 원출처 인용(있는 경우)과 인용 부재 상태
- 이용 조건을 별도로 확인해야 한다는 표시

## 판단과 주의점

모든 후보는 PubChem 화합물 기록 URL을 갖지만, 표본의 모든 설명 문장에 기여 원자료 인용이 표시되지는 않았다. 따라서 원출처 인용이 없는 행은 `PubChem`이라는 문서 제공자까지는 추적되지만, 문장 수준의 최초 제공처는 이 점검만으로 확인되지 않는다. LogS 측정값은 AqSolDB `ID` 접두어를 통해 해당 원자료 묶음과 논문 참고문헌으로 별도로 추적할 수 있다. PubChem 설명에 인용이 있더라도 그 인용은 출처 표시이지, 해당 annotation의 재배포 허가를 자동으로 뜻하지 않는다. 전체 후보 100건을 전부 해소하는 데 매달리지 않고, 실제로 선택해 색인할 외부 문서의 원문·출처·이용 조건을 확인한다. 확인이 안 되면 그 문서는 보류하고 다른 문서를 고른다.

## 실제 색인 대상에 적용할 출처 확인 절차 (2026-10-21)

PubChem의 공식 문서는 PUG-View annotation에 항목별 attribution이 제공되고, 개별 기록의 출처 상세에서 원 기록과 라이선스 링크를 확인할 수 있다고 설명한다. 따라서 PubChem CID와 기록 URL만으로 annotation의 원출처·이용 조건이 확인된 것으로 처리하지 않는다. 실제 사용할 각 annotation에 대해 heading, 문장, attribution/기여자, 원 기록 URL, 라이선스 링크 또는 명시된 조건을 저장한다. 링크된 이용 조건이 없거나 재사용 범위가 불명확하면 본문을 색인하지 않고 문서 출처 목록에 `보류`로 남긴다.

현재 후보 CSV는 예비 표본조사 자료다. 특정 후보가 최종 인덱스에 들어가기 전에는 해당 CID의 PUG-View 응답과 PubChem 화면에서 실제 annotation별 출처를 다시 열어 확인해야 한다. 출처 기록에는 확인일과 검토한 URL을 남긴다. PubChem의 일반 서비스 인용은 PubChem 자체를 인용하는 보조 서지정보이며, annotation의 기여 출처나 이용 허가를 대체하지 않는다.

### 최초 개별 후보 검토: AqSolDB A-454

- PubChem 후보 파일의 A-454는 CID 6540이며, 설명 문장 attribution은 NTP Chemical Repository Database (1992)로 표시된다.
- [PubChem CID 6540](https://pubchem.ncbi.nlm.nih.gov/compound/6540)와 [NOAA CAMEO Chemicals CH21145](https://cameochemicals.noaa.gov/report?key=CH21145)를 대조했다. CAMEO는 Tributoxyethyl phosphate, CAS 78-51-3로 표시하고 동일한 physical description 문장을 NTP (1992) 출처와 함께 제공한다.
- NOAA 안내는 별도 표시가 없는 NOAA 정보 대부분이 public domain이며 NOAA 출처 표기를 요구한다고 설명한다. NTP도 별도 저작권 표시가 없는 NTP 웹사이트 정보는 public domain이라고 안내한다. 이 CAMEO 레코드에서는 별도 저작권 문구를 확인하지 못했다. 이에 교육용 색인에는 CAMEO 문서 전체가 아니라 `Physical description`의 짧은 문장만 NOAA CAMEO/NTP 1992 attribution과 함께 넣을 수 있는 후보로 판정했다.
- CAMEO 페이지에는 안전, 취급, 유출 대응 등 이 프로젝트 범위를 벗어나는 내용도 있다. 이 문서의 해당 부분은 색인하지 않는다. 다른 PubChem 항목이나 다른 제공처에 이 이용 판단을 확대 적용하지 않는다.
- 기록: `../research/provenance/approved_external_sources.csv`. 이는 현재 검토 완료한 개별 문서 1건이며, 나머지 후보의 상태는 바뀌지 않는다.

### 출처군 표본 검토 및 색인 데이터 확장 (2026-10-21)

후보 100건 중 원출처가 표시된 26건을 출처군 단위로 묶어 후속 검토 대상을 정했다. 표본에는 NTP Chemical Repository (8건), U.S. Coast Guard CHRIS (5건), ATSDR 독성 프로필 (4건), EPA EHS Chemical Profiles (3건), 기타·혼합 인용 (6건)이 있었다. 이 수치는 조사 표본의 분포이지 전체 PubChem 문서의 분포가 아니다. 출처군 이름이 같다는 이유만으로 일괄 승인하지 않았다.

이번 단계에서 CAMEO 원문과 화합물 식별자를 개별 대조해 승인 레코드를 총 3건으로 늘렸다.

- **A-454 / CID 6540 / tris(2-butoxyethyl) phosphate:** 기존 검토. CAMEO CH21145, CAS 78-51-3, NTP(1992) attribution을 확인하고 짧은 외관 설명만 기록.
- **A-5538 / CID 8418 / anthracene:** CAMEO anthracene 레코드의 CAS 120-12-7과 USCG(1999) attribution을 확인. 일반 물리 묘사 한 문장만 기록하며, 이 문장은 정량 용해도 측정값이 아니다.
- **A-4518 / CID 7975 / 2-methylpyridine:** CAMEO CH8856의 CAS 109-06-8을 확인. NTP(1992) attribution이 붙은 물 용해도 필드 한 건만, 원 단위와 온도를 유지해 기록했다. AqSolDB LogS 라벨과 직접 같다고 가정하지 않는다.

CAMEO 이용조건은 일부 제공 기관 데이터에 별도 저작권 제한이 있을 수 있다고 알리며 DuPont, CAS, NFPA, AEGL, ERPG 자료를 제한 대상으로 열거한다. NOAA 또한 웹사이트의 모든 내용이 NOAA 제공은 아니므로 크레딧을 확인하라고 안내한다. 따라서 이 단계에서는 해당 제한 범주를 제외하고 각 승인 행의 attribution을 그대로 보존했으며, 판정 범위를 지정한 발췌문으로 제한했다. 출처별 세부 판정은 `../research/provenance/approved_external_sources.csv`, 미검토 출처군은 `../research/provenance/source_family_review.csv`에 기록했다.

ATSDR, EPA 및 나머지 PubChem 후보는 원문과 이용 조건을 확인하지 않았으므로 보류 상태다. 앞의 세 CAMEO 승인 발췌만 별도로 GMS 임베딩 및 Chroma 색인을 완료했으며, 보류 후보는 색인하지 않았다.

### E-1274 아스피린 후보 조사 (2026-10-21)

아스피린은 프로젝트의 핵심 화합물로 확정하지 않았다. 사용자가 입력하기 쉬운 이름이고 별칭 매핑 버그를 드러낸 대표 UI 예시다. 현재 승인 문헌 색인은 A-454, A-5538, A-4518에 연결돼 있으며, 질문에 직접 수용해도 근거가 있는 시연은 A-4518이 우선이다. 아스피린 후보를 조사한 이유는 그 이름을 필수 주제로 밀기 위해서가 아니라, 데이터셋의 아스피린 레코드와 문서 출처 가능성을 확인하기 위해서다.

- AqSolDB `E-1274` InChIKey `BSYNRYMUTXBXSQ-UHFFFAOYSA-N`에서 PubChem CID 2244를 구조 키로 조회하고, 해당 CID의 InChIKey를 다시 대조했다.
- PubChem PUG-View의 `Solubility` 주석 6건을 수집했다. 제공 출처는 CAMEO/NTP, DrugBank, HSDB 2건, ILO-WHO ICSC, NIOSH다. 각 수치에 표시된 출처 인용, 원출처 링크(제공되는 경우), PubChem URL, 이용 조건 메모를 `../research/provenance/external_document_candidates.jsonl`에 보존했다.
- 이용 조건이 같지 않다. 예를 들어 DrugBank는 비상업(CC BY-NC 4.0) 조건을 표시하고, CAMEO는 기여 데이터 일부에 별도 저작권 제한이 있을 수 있다고 밝히며, HSDB는 PUG-View source record에 라이선스 메모가 없다. ILO-WHO ICSC에는 CC BY 4.0이 표시되지만 정확한 재사용·변경표시·귀속 요건을 확인해야 한다. 어느 항목도 수집만으로 색인 승인하지 않았다.
- PubChem 자체 안내는 레코드 안에서 항목별 제공자·원 사이트·라이선스를 확인하고 해당 출처의 조건이 재사용을 결정한다고 설명한다. 따라서 이 6개 후보는 모두 `selected_pending_human_review`, `index_eligible=false`로 저장됐으며, 현 앱과 벡터 색인에 포함되지 않는다.
- 위키백과 aspirin 후보도 함께 확인했지만 소개 문서는 용해도 측정 근거가 아니어서 핵심 증거로 채택하지 않는다.

이번 결과는 “아스피린이 중요하다”는 결론이 아니다. 프로젝트의 중심은 AqSolDB 화합물 집합을 대상으로 하는 근거 추적형 RAG이며, 단일 유명 물질은 시연·입력 검증 사례에 한정한다.


### 보조 근거와 Top-k 비교용 색인 보강 (2026-10-21)

A-4518 (2-methylpyridine)의 두 번째 근거로 Wikipedia의 [2-Methylpyridine 문서, revision oldid 1365419483](https://en.wikipedia.org/w/index.php?title=2-Methylpyridine&oldid=1365419483)를 검토했다. 문서는 CAS 109-06-8, PubChem CID 7975와 InChIKey `BSKHPKMHTQYZBB-UHFFFAOYSA-N`를 표시해 선택한 AqSolDB 레코드와 일치한다. 문서의 수용해도 항목은 “miscible”이라고 적고, 표준 상태를 별도 조건이 없을 때 25 °C·100 kPa로 설명한다. 다만 화학 인포박스 자체 안내가 데이터 정확성을 보장하지 않는다고 명시한다. 따라서 정량 측정값이나 NOAA/NTP 원자료를 대체하는 증거로 쓰지 않고, 커뮤니티 편집 2차 자료라는 한계를 RAG 문서와 화면에 보존한다.

페이지는 CC BY-SA 4.0을 표시한다. 프로젝트는 페이지 제목·고정 revision·링크를 출처 attribution에 남기고, 발췌물에 라이선스 URL과 동일조건(ShareAlike) 메모를 붙였다. 이를 근거로 승인 CSV에 포함하고 Chroma에 한 청크로 색인했다. 자세한 판정은 `../research/provenance/approved_external_sources.csv`의 `WIKIPEDIA-2-METHYLPYRIDINE-20260722` 행에서 확인할 수 있다.

이 문서 추가 후 동일 질문의 GMS 벡터 검색 결과를 비교했다. Top-k 1은 Wikipedia 발췌 1건, Top-k 3은 Wikipedia와 NOAA/NTP 발췌 2건을 반환했다. 이는 검색 계층에서 F2006 결과 차이를 보인 것이며, UI 슬라이더 조작은 브라우저 접근 제한으로 아직 확인하지 않았다.


이번 보조자료 색인 뒤 A-4518 질문으로 retrieve/generate 그래프를 다시 실행했다. 응답은 AqSolDB LogS `1.0309150604`(로컬 Train 행과 일치), Wikipedia “miscible” 보조 표기, NOAA/CAMEO 문서에 NTP(1992) 출처로 표시된 `≥100 mg/mL at 68°F`를 구분했다. citation ID 1/2/3은 각각 해당 메타데이터·Wikipedia·NOAA 문서의 실제 검색 결과와 일치했다.
