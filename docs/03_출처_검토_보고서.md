# AqSolDB 화합물 문서 출처 표본 점검

## 목적

AI 코어 프로젝트의 데이터 출처·이용 조건을 기록하기 위해 AqSolDB 표본을 PubChem으로 연결해 문서 후보의 출처 추적 가능성을 살폈다. 체크리스트의 100개 이상 조건은 화합물 메타데이터 항목 수에 해당하며 외부 문서 100건을 요구하는 것으로 읽지 않는다. 이 파일은 원출처·이용 조건 검토가 끝난 최종 승인 목록이 아니다.

## 표본 및 결과

- 입력: `train.csv`와 `test.csv` 전체를 합친 뒤 파일 순서에 따라 일정 간격으로 뽑은 300개 표본
- 데이터 행 수: train 7,488, test 2,494 (총 9,982)
- 정확한 구조 대조 키: AqSolDB `InChIKey`와 PubChem Compound ID(CID)
- 표본에서 CID에 연결: 285 / 300
- PubChem Record Description 텍스트 존재: 179 / 300
- PubChem 설명 항목에 원출처 인용까지 붙은 행: 41 / 300
- 이 CSV에 담은 설명 문장 후보: 100개 (안전·위험 안내, 관계 이동/중복 문구, 40자 미만 문장을 제외)
- 선택한 후보 중 PubChem에 원출처 인용이 표시된 항목: 26 / 100

## AqSolDB 데이터 이용 조건 확인

Harvard Dataverse의 공식 데이터셋 API를 확인했다. 최신 공개 버전은 v1이며 라이선스는 CC0 1.0으로 표시된다. 공식 원본 파일은 `curated-solubility-dataset.tab` (file ID 3407241, 3,844,092 bytes)이다. 프로젝트 폴더의 `train.csv`/`test.csv`는 Hugging Face에 올라온 분할 사본이므로 제출 시 canonical DOI와 논문을 인용하고, 사용한 분할 사본 URL도 README에 함께 기록한다.

## LogS 측정값의 원자료 추적

AqSolDB 논문은 통합 파일의 `ID`가 원본 데이터셋을 표시한다고 설명한다. 따라서 `A-3`처럼 접두어를 분리해 A-I 중 어느 원자료 묶음에 속하는지 연결할 수 있다. 후보 CSV와 audit CSV에 이 접두어, 원자료 이름, 논문 내 참고문헌 번호를 추가했다. 이 정보는 실험 LogS 값의 출처를 추적하는 데 쓰며, PubChem 설명 문장의 원출처와는 별도 provenance다.

- A: eChemPortal/OECD [14]
- B, D: EPI Suite 원자료 [15], [17]
- C: Raevsky et al. [16]
- E: Huuskonen et al. [1]
- F, H: Wang et al. 계열 [8]; H는 Jain–Yalkowsky 자료 정리본 [19]에 기반
- G: Delaney et al. [2]
- I: Goodman Group corrected Solubility Challenge [20]

## 각 행의 출처 추적 필드

새 폴더 구조로 옮긴 뒤 로컬 9,982행을 다시 집계했다. A-I 접두어가 모두 매핑 파일에 존재했고, 미매핑 접두어/행은 0건이었다. 이는 각 행이 AqSolDB 논문 Table 1의 원자료 묶음으로 연결된다는 확인이다. 개별 측정값의 원 논문 원문을 행마다 대조하거나 upstream 자료의 별도 라이선스를 확인한 결과는 아니다.

- AqSolDB ID 및 A-I 접두어로 추적한 원자료 출처 코드, InChIKey, SMILES, 실험 LogS, Harvard Dataverse DOI와 논문 인용
- PubChem CID 및 해당 화합물의 고정 URL
- PubChem Record Description 원문 텍스트
- PubChem이 표시한 원출처 인용(있는 경우)과 인용 부재 상태
- 이용 조건을 별도로 확인해야 한다는 표시

## 판단과 주의점

모든 후보는 PubChem 화합물 기록 URL을 갖지만, 표본의 모든 설명 문장에 기여 원자료 인용이 표시되지는 않았다. 따라서 원출처 인용이 없는 행은 `PubChem`이라는 문서 제공자까지는 추적되지만, 문장 수준의 최초 제공처는 이 점검만으로 확인되지 않는다. LogS 측정값은 AqSolDB `ID` 접두어를 통해 해당 원자료 묶음과 논문 참고문헌으로 별도로 추적할 수 있다. PubChem 설명에 인용이 있더라도 그 인용은 출처 표시이지, 해당 annotation의 재배포 허가를 자동으로 뜻하지 않는다. 전체 후보 100건을 전부 해소하는 데 매달리지 않고, 실제로 선택해 색인할 외부 문서의 원문·출처·이용 조건을 확인한다. 확인이 안 되면 그 문서는 보류하고 다른 문서를 고른다.

## 실제 색인 대상에 적용할 출처 확인 절차 (2026-10-21)

PubChem의 공식 문서는 PUG-View annotation에 항목별 attribution이 제공되고, 개별 기록의 출처 상세에서 원 기록과 라이선스 링크를 확인할 수 있다고 설명한다. 따라서 PubChem CID와 기록 URL만으로 annotation의 원출처·이용 조건이 확인된 것으로 처리하지 않는다. 실제 사용할 각 annotation에 대해 heading, 문장, attribution/기여자, 원 기록 URL, 라이선스 링크 또는 명시된 조건을 저장한다. 링크된 이용 조건이 없거나 재사용 범위가 불명확하면 본문을 색인하지 않고 문서 출처 목록에 `보류`로 남긴다.

현재 후보 CSV는 예비 표본조사 자료다. 특정 후보가 최종 인덱스에 들어가기 전에는 해당 CID의 PUG-View 응답과 PubChem 화면에서 실제 annotation별 출처를 다시 열어 확인해야 한다. 출처 기록에는 확인일과 검토한 URL을 남긴다. PubChem의 일반 서비스 인용은 PubChem 자체를 인용하는 보조 서지정보이며, annotation의 기여 출처나 이용 허가를 대체하지 않는다.

### 최초 개별 후보 검토: AqSolDB A-454

- PubChem 후보 파일의 A-454는 CID 6540이며, 설명 문장 attribution은 NTP Chemical Repository Database (1992)로 표시된다.
- [PubChem CID 6540](https://pubchem.ncbi.nlm.nih.gov/compound/6540)와 [NOAA CAMEO Chemicals CH21145](https://cameochemicals.noaa.gov/report?key=CH21145)를 대조했다. CAMEO는 Tributoxyethyl phosphate, CAS 78-51-3로 표시하고 동일한 physical description 문장을 NTP (1992) 출처와 함께 제공한다.
- NOAA 안내는 별도 표시가 없는 NOAA 정보 대부분이 public domain이며 NOAA 출처 표기를 요구한다고 설명한다. NTP도 별도 저작권 표시가 없는 NTP 웹사이트 정보는 public domain이라고 안내한다. 이 CAMEO 레코드에서는 별도 저작권 문구를 확인하지 못했다. 이에 교육용 색인에는 CAMEO 문서 전체가 아니라 `Physical description`의 짧은 문장만 NOAA CAMEO/NTP 1992 attribution과 함께 넣을 수 있는 후보로 판정했다.
- CAMEO 페이지에는 안전, 취급, 유출 대응 등 이 프로젝트 범위를 벗어나는 내용도 있다. 이 문서의 해당 부분은 색인하지 않는다. 다른 PubChem 항목이나 다른 제공처에 이 이용 판단을 확대 적용하지 않는다.
- 기록: `../data/approved_external_sources.csv`. 이는 현재 검토 완료한 개별 문서 1건이며, 나머지 후보의 상태는 바뀌지 않는다.

### 출처군 표본 검토 및 색인 데이터 확장 (2026-10-21)

후보 100건 중 원출처가 표시된 26건을 출처군 단위로 묶어 후속 검토 대상을 정했다. 표본에는 NTP Chemical Repository (8건), U.S. Coast Guard CHRIS (5건), ATSDR 독성 프로필 (4건), EPA EHS Chemical Profiles (3건), 기타·혼합 인용 (6건)이 있었다. 이 수치는 조사 표본의 분포이지 전체 PubChem 문서의 분포가 아니다. 출처군 이름이 같다는 이유만으로 일괄 승인하지 않았다.

이번 단계에서 CAMEO 원문과 화합물 식별자를 개별 대조해 승인 레코드를 총 3건으로 늘렸다.

- **A-454 / CID 6540 / tris(2-butoxyethyl) phosphate:** 기존 검토. CAMEO CH21145, CAS 78-51-3, NTP(1992) attribution을 확인하고 짧은 외관 설명만 기록.
- **A-5538 / CID 8418 / anthracene:** CAMEO anthracene 레코드의 CAS 120-12-7과 USCG(1999) attribution을 확인. 일반 물리 묘사 한 문장만 기록하며, 이 문장은 정량 용해도 측정값이 아니다.
- **A-4518 / CID 7975 / 2-methylpyridine:** CAMEO CH8856의 CAS 109-06-8을 확인. NTP(1992) attribution이 붙은 물 용해도 필드 한 건만, 원 단위와 온도를 유지해 기록했다. AqSolDB LogS 라벨과 직접 같다고 가정하지 않는다.

CAMEO 이용조건은 일부 제공 기관 데이터에 별도 저작권 제한이 있을 수 있다고 알리며 DuPont, CAS, NFPA, AEGL, ERPG 자료를 제한 대상으로 열거한다. NOAA 또한 웹사이트의 모든 내용이 NOAA 제공은 아니므로 크레딧을 확인하라고 안내한다. 따라서 이 단계에서는 해당 제한 범주를 제외하고 각 승인 행의 attribution을 그대로 보존했으며, 판정 범위를 지정한 발췌문으로 제한했다. 출처별 세부 판정은 `../data/approved_external_sources.csv`, 미검토 출처군은 `../research/provenance/source_family_review.csv`에 기록했다.

ATSDR, EPA 및 나머지 PubChem 후보는 원문과 이용 조건을 확인하지 않았으므로 보류 상태다. 앞의 세 CAMEO 승인 발췌만 별도로 GMS 임베딩 및 Chroma 색인을 완료했으며, 보류 후보는 색인하지 않았다.

### E-1274 아스피린 후보 조사 (2026-10-21)

아스피린은 프로젝트의 핵심 화합물로 확정하지 않았다. 사용자가 입력하기 쉬운 이름이고 별칭 매핑 버그를 드러낸 대표 UI 예시다. 현재 승인 문헌 색인은 A-454, A-5538, A-4518에 연결돼 있으며, 질문에 직접 수용해도 근거가 있는 시연은 A-4518이 우선이다. 아스피린 후보를 조사한 이유는 그 이름을 필수 주제로 밀기 위해서가 아니라, 데이터셋의 아스피린 레코드와 문서 출처 가능성을 확인하기 위해서다.

- AqSolDB `E-1274` InChIKey `BSYNRYMUTXBXSQ-UHFFFAOYSA-N`에서 PubChem CID 2244를 구조 키로 조회하고, 해당 CID의 InChIKey를 다시 대조했다.
- PubChem PUG-View의 `Solubility` 주석 6건을 수집했다. 제공 출처는 CAMEO/NTP, DrugBank, HSDB 2건, ILO-WHO ICSC, NIOSH다. 각 수치에 표시된 출처 인용, 원출처 링크(제공되는 경우), PubChem URL, 이용 조건 메모를 `../research/provenance/external_document_candidates.jsonl`에 보존했다.
- 이용 조건이 같지 않다. 예를 들어 DrugBank는 비상업(CC BY-NC 4.0) 조건을 표시하고, CAMEO는 기여 데이터 일부에 별도 저작권 제한이 있을 수 있다고 밝히며, HSDB는 PUG-View source record에 라이선스 메모가 없다. ILO-WHO ICSC에는 CC BY 4.0이 표시되지만 정확한 재사용·변경표시·귀속 요건을 확인해야 한다. 어느 항목도 수집만으로 색인 승인하지 않았다.
- PubChem 자체 안내는 레코드 안에서 항목별 제공자·원 사이트·라이선스를 확인하고 해당 출처의 조건이 재사용을 결정한다고 설명한다. 따라서 이 6개 후보는 모두 `selected_pending_human_review`, `index_eligible=false`로 저장됐으며, 현 앱과 벡터 색인에 포함되지 않는다.
- 위키백과 aspirin 후보도 함께 확인했지만 소개 문서는 용해도 측정 근거가 아니어서 핵심 증거로 채택하지 않는다.

이번 결과는 “아스피린이 중요하다”는 결론이 아니다. 프로젝트의 중심은 AqSolDB 화합물 집합을 대상으로 하는 근거 추적형 RAG이며, 단일 유명 물질은 시연·입력 검증 사례에 한정한다.


### 보조 근거와 Top-k 비교용 색인 보강 (2026-10-21)

A-4518 (2-methylpyridine)의 두 번째 근거로 Wikipedia의 [2-Methylpyridine 문서, revision oldid 1365419483](https://en.wikipedia.org/w/index.php?title=2-Methylpyridine&oldid=1365419483)를 검토했다. 문서는 CAS 109-06-8, PubChem CID 7975와 InChIKey `BSKHPKMHTQYZBB-UHFFFAOYSA-N`를 표시해 선택한 AqSolDB 레코드와 일치한다. 문서의 수용해도 항목은 “miscible”이라고 적고, 표준 상태를 별도 조건이 없을 때 25 °C·100 kPa로 설명한다. 다만 화학 인포박스 자체 안내가 데이터 정확성을 보장하지 않는다고 명시한다. 따라서 정량 측정값이나 NOAA/NTP 원자료를 대체하는 증거로 쓰지 않고, 커뮤니티 편집 2차 자료라는 한계를 RAG 문서와 화면에 보존한다.

페이지는 CC BY-SA 4.0을 표시한다. 프로젝트는 페이지 제목·고정 revision·링크를 출처 attribution에 남기고, 발췌물에 라이선스 URL과 동일조건(ShareAlike) 메모를 붙였다. 이를 근거로 승인 CSV에 포함하고 Chroma에 한 청크로 색인했다. 자세한 판정은 `../data/approved_external_sources.csv`의 `WIKIPEDIA-2-METHYLPYRIDINE-20260722` 행에서 확인할 수 있다.

이 문서 추가 후 동일 질문의 GMS 벡터 검색 결과를 비교했다. Top-k 1은 Wikipedia 발췌 1건, Top-k 3은 Wikipedia와 NOAA/NTP 발췌 2건을 반환했다. 이는 검색 계층에서 F2006 결과 차이를 보인 것이며, UI 슬라이더 조작은 브라우저 접근 제한으로 아직 확인하지 않았다.


이번 보조자료 색인 뒤 A-4518 질문으로 retrieve/generate 그래프를 다시 실행했다. 응답은 AqSolDB LogS `1.0309150604`(로컬 Train 행과 일치), Wikipedia “miscible” 보조 표기, NOAA/CAMEO 문서에 NTP(1992) 출처로 표시된 `≥100 mg/mL at 68°F`를 구분했다. citation ID 1/2/3은 각각 해당 메타데이터·Wikipedia·NOAA 문서의 실제 검색 결과와 일치했다. AppTest에서도 외부 인용 두 건의 카드와 링크가 보이는 것을 확인했다.


### C-533 카페인 후보 탐색 (2026-10-22)

AqSolDB train의 카페인 레코드 C-533을 골라 PubChem PUG-View의 용해도 주석을 확인했다. 후보는 9건이었고 CAMEO/NTP, DrugBank, HSDB, HMDB, ILO-WHO ICSC가 섞여 있었다. GMS 선별은 한 번 실행했다. 후보들은 우선 검토 대기에 두고, 자동 포함 결과를 출처 승인으로 간주하지 않았다. 일부는 물 용해도가 아닌 다른 용매의 용해도이고, 라이선스 정보가 없거나 서로 맞지 않는 항목도 있었다. 그 뒤 NOAA 원문과 출처별 조건을 대조해 NOAA CAMEO/NTP의 수용해도 한 건만 제한 범위로 승인했다. 나머지 후보는 계속 검토 대기다.

특히 PubChem의 [ILO-WHO ICSC 출처 페이지](https://pubchem.ncbi.nlm.nih.gov/source/ILO-WHO%20International%20Chemical%20Safety%20Cards%20%28ICSCs%29)는 CC BY 4.0을 표시하지만, 연결된 [ICSC 0405 원문](https://chemicalsafety.ilo.org/dyn/icsc/showcard.display?p_card_id=0405&p_version=2)은 1998년판이며 “All rights reserved”라고 적혀 있다. ILO의 [권리·이용 정책](https://www.ilo.org/rights-and-permissions)은 2023년 5월 이전 출판물이 자동으로 CC BY가 되는 것은 아니라고 설명한다. 조건이 정리되기 전에는 이 발췌를 색인하지 않는다.

이번 탐색으로 데이터 건수를 바로 늘리기보다, 화합물별로 측정값·측정 조건·원출처가 확인되는 자료를 먼저 고르는 편이 낫다는 점을 확인했다. 후보 전문과 항목별 검토 메모는 `research/provenance/external_document_candidates.jsonl`에 있다.


### C-533 카페인 문헌 검토 (2026-10-22)

AqSolDB Train의 `C-533 / caffeine`와 NOAA CAMEO의 CAFFEINE 자료를 대조했다. InChIKey `RYYVLZVUVIJVGH-UHFFFAOYSA-N`, PubChem CID 2519, NOAA 페이지의 CAS 58-08-2가 서로 맞는다. NOAA CAMEO 페이지의 Water Solubility는 `10 to 50 mg/mL at 73°F (NTP, 1992)`로 기록되어 있다. 값·단위·온도·원출처가 함께 있어 용해도 근거로 활용할 수 있지만, 해당 페이지는 측정법을 제공하지 않으므로 그 정보는 추정하지 않는다.

이용 조건은 NOAA CAMEO [Terms and Conditions](https://m.cameochemicals.noaa.gov/help/reference/terms_and_conditions.htm)와 NOAA [content guidance](https://www.noaa.gov/office-education/outreach-communication/faq), NTP [Web Policies](https://ntp.niehs.nih.gov/support/policies)를 확인했다. CAMEO는 DuPont, CAS, NFPA, AEGL, ERPG 등 특정 제3자 데이터 제한을 명시한다. 이 발췌는 그 범주가 아니라 NTP 1992 출처로 표시된 수용해도 값이며, NTP는 별도 저작권 표시가 없는 NTP 웹사이트 정보를 공공영역으로 설명한다. 이를 근거로 값 한 항목과 출처만 제한적으로 승인했다. CAMEO의 안전·건강·취급·대응 등 다른 부분은 가져오지 않는다.

원문: [NOAA CAMEO Chemicals — Caffeine](https://cameochemicals.noaa.gov/chemical/19945). 승인 CSV·후보 상태·로컬 입력 JSONL에 반영했다. GMS 임베딩으로 Chroma 색인을 갱신해 기존 7 / 추가 1 / 총 8청크를 확인했다. 이후 카페인 질문의 벡터 검색이 NOAA/CAMEO 발췌를 반환했고, 생성 답변은 `[근거 2]`로 값·단위·온도·NTP 출처를 인용했다. AqSolDB LogS는 `[근거 1]`로 따로 제시되어 문헌 수용해도 값과 구분됐다.

### B-524 타우린 자료 조사 및 검토 (2026-10-22)

사용자가 실제 한글 이름으로 찾는 상황을 점검했다. AqSolDB Train에 `B-524 / taurine` 레코드가 있으며 InChIKey는 `XOAAWQZATWQOTB-UHFFFAOYSA-N`이다. 데이터에는 들어 있지만 앱 별칭에 `타우린`이 없었던 검색 문제를 확인해 별칭 검색을 보완했다.

색인한 외부 발췌는 다음 세 건이다.

- **NOAA CAMEO CH21060:** CAS 107-35-7과 레코드의 화합물 정체성을 대조했다. NTP(1992) 귀속의 `50 to 100 mg/mL at 74.3°F` 수용해도 한 항목만 선택했다. 기존 CAMEO/NTP 발췌 검토와 같은 제한 범위를 적용하고, 안전·건강·취급·대응 정보는 색인에서 제외했다. 원문: https://cameochemicals.noaa.gov/report?key=CH21060
- **Wikipedia Taurine, revision oldid 1376465253:** 본문은 타우린의 양쪽성 이온 구조와 술폰산기의 이온화 내용을 설명한다. 페이지에 표시된 CC BY-SA 4.0 조건을 적용해 고정 revision, attribution, 한국어 번역·요약 사실 및 동일 라이선스 메모를 저장했다. 이 문서는 구조에 관한 2차 자료이며 용해도 기여도를 직접 정량화하지 않는다. 원문: https://en.wikipedia.org/w/index.php?title=Taurine&oldid=1376465253
- **Wikipedia Water, revision oldid 1379351727:** 물이 극성 용매이고 친수성 유기 분자를 녹인다는 일반 설명만 한국어 요약으로 기록했다. 타우린 개별 페이지가 아니므로 화합물별 실험 근거가 아니라 일반 배경으로만 사용한다. CC BY-SA 4.0의 attribution 및 ShareAlike 조건을 기록했다. 원문: https://en.wikipedia.org/w/index.php?title=Water&oldid=1379351727

`타우린은 왜 물에 잘 녹나요?`라는 질문은 타우린 구조 설명과 물의 극성 용매 설명을 함께 찾아 해석할 수 있다. 다만 “양쪽성 이온이 용해도를 얼마나 높였는지”를 이 자료가 정량적으로 입증한다고 말하지 않도록 범위 메모를 붙였다. CAMEO의 문헌 수용해도 기록은 별도 측정치로 제시하고 AqSolDB LogS와 직접 같은 값처럼 바꾸지 않는다.

OpenStax의 물 용매 설명과 Springer의 타우린 논문도 후보로 살펴봤으나 색인하지 않았다. OpenStax 페이지는 사전 서면 허가 없이 생성형 AI 서비스에 내용을 넣는 것을 제한한다고 명시한다. Springer 논문은 CC BY-NC-ND 4.0 조건으로, 본 프로젝트의 번역·청킹된 RAG 발췌에 그대로 적용하기 어렵다.

세 문서는 `../data/approved_external_sources.csv`에 원출처·식별 대조·이용 조건·범위와 함께 기록하고 `data/curated_external_documents.jsonl` 및 `indexes/aqsoldb_documents`에 반영했다. 색인 실행 결과는 기존 4 / 추가 3 / 총 7청크다. 한국어 로컬 검색 확인에서 `타우린`은 B-524 한 건을 반환했고, `타우린은 왜 물에 잘 녹나요?`는 NOAA 수용해도, Wikipedia 물의 용매 설명, Wikipedia 타우린 구조 설명을 각각 근거로 반환했다.


### E-1274 아스피린 후보의 검토·색인 연결 (2026-10-22)

기존 GMS 선별에 포함된 `pubchem-cid-2244-solubility-ref-9-1`을 NOAA 원문과 대조했다. AqSolDB E-1274의 InChIKey는 `BSYNRYMUTXBXSQ-UHFFFAOYSA-N`, PubChem CID는 2244이며, [NOAA CAMEO 원문](https://cameochemicals.noaa.gov/chemical/19712)은 acetylsalicylic acid와 aspirin을 같은 항목으로 표시한다. 수용해도 기록은 `less than 1 mg/mL at 73°F (NTP, 1992)`다. 정확히 1 mg/mL라는 뜻으로 바꾸지 않도록 상한 표현을 보존했다.

CAMEO 이용 조건은 requests로 HTTP 200 응답을 받아 확인했고, NTP Web Policies와 NOAA 콘텐츠 안내도 대조했다. 기존 CAMEO/NTP 발췌와 동일하게 이 한 물성 항목과 출처만 제한 승인했다. 안전·건강·취급 및 별도 제한 대상 제3자 데이터는 가져오지 않았다. 승인 문서 ID는 `CAMEO-ASPIRIN-NTP-20261022`이며 후보 행에 이 ID를 연결했다. 원래 후보 전체는 계속 `index_eligible=false`로 두고 승인 발췌만 별도로 색인했다.

색인 결과는 기존 8 / 추가 1 / 총 9건이고, 재실행은 기존 9 / 추가 0 / 총 9건이었다. PubChem 단독 수집도 실행해 후보 6건·GMS 선별 6건을 확인했고 같은 질문의 재실행은 API 재호출 없이 캐시를 사용했다. 원문과 이용 조건의 검토 없이 후보를 일괄 승인하지 않았다.

승인 CSV는 제출본에서도 읽을 수 있도록 `data/approved_external_sources.csv`로 옮겼다. 미검토 후보와 수집 캐시는 research에 남겨 런타임 입력과 분리했다.

## 문서 확보 범위와 남은 검토

원본 요구사항 4쪽은 약 100건 이상의 항목 메타데이터와 각 항목에 연결되는 설명 문서를 요구한다. 설명 문서를 찾았다는 사실과 그 내용을 RAG에 재사용할 수 있다는 판정은 구분해야 한다.

## 점검 결과

기존 출처 균형 메타데이터 표본 100건 중 승인 문헌이 연결된 항목은 5건이었다. 이 표본으로 전체 문서 연결 요건을 충족했다고 볼 수 없어 종합 완료는 보류했다. 당시 항목별 결과는 `docs/evidence/metadata_document_coverage.csv`에 보존했다.

기존 PubChem 조사 300건을 다시 대조하니 Train에 속하고 로컬 InChIKey가 일치하며 실제 Record Description 본문이 저장된 항목은 136건이었다. 이 중 출처 인용 문자열까지 있는 것은 35건이다. Test 항목은 과제용 메타데이터 색인 대상에서 제외했다.

이를 바탕으로 승인 문헌이 있는 6종을 포함하고 출처 그룹을 분산해 문서 확보 대상 100건을 구성했다. 목록은 `data/document_discovery_manifest.csv`이며, 각 행에 화합물 ID·InChIKey·문서 URL·확보 근거·검토 상태·본문 문자 수와 SHA-256을 기록했다. 미승인 본문 자체는 이 제출용 목록에 복제하지 않았다. `python src/document_coverage.py`로 기존 조사 기록에서 재생성할 수 있다. 이 명령의 재생성에는 보조 조사 자료 `research/provenance/pubchem_source_audit.csv`가 필요하다. 이미 생성된 목록으로 앱과 색인을 실행할 때는 research 폴더가 필요하지 않다.

| 구분 | 현재 범위 | 의미 |
|---|---:|---|
| 문서 확보 대상으로 정한 Train 메타데이터 | 100종 | 모든 행에 설명 문서 확보 기록과 URL이 있음 |
| 검토 완료 발췌가 있는 항목 | 6종 | 승인 발췌 9건을 문헌 컬렉션에 색인 |
| 검토 대기 항목 | 94종 | 기존 설명 본문 확보 기록은 있으나 관련성·원출처·이용 조건 검토가 남음 |
| 앱의 이름·수치 검색 범위 | Train 7,488행 | 전체 항목에서 문헌 답변이 가능하다는 뜻은 아님 |

새 대상의 메타데이터는 `aqsoldb_compounds_linked`에 100건 색인했다. 각 메타데이터에 연결 문서 URL과 검토 상태를 넣었으며, 미승인 설명 본문은 포함하지 않았다. 재실행 결과도 기존 100 / 신규 0 / 총 100이다. 이전 `aqsoldb_compounds`는 기록 보존용으로 유지하고 현재 기본 컬렉션으로 사용하지 않는다.

## 해석과 제한

이 목록은 항목별 설명 문서 확보 가능성을 기존 수집 기록으로 확인한 것이다. 100종 모두에 수용해도 원인·pH 효과를 설명할 자료가 있다는 뜻도, 100종 모두 RAG 답변이 준비됐다는 뜻도 아니다. 일반 Record Description이 실제 학습 질문에 충분한지는 별도로 검토해야 한다.

현재 승인된 6종은 A-454, A-5538, A-4518, B-524(타우린), C-533(카페인), E-1274(아스피린)이다. 답변 가능한 주장과 한계는 각 승인 행의 범위 메모를 따른다. 특히 외관 발췌만 있는 항목에서 용해 원인을 설명한다고 약속하지 않는다.

남은 94종을 검토 없이 승인하거나, PubChem에 실렸다는 이유만으로 기여 출처의 이용 조건을 같게 취급하지 않는다. 필수 기능 검증과 별개로 이 문서 범위의 제한은 최종 보고서에도 유지한다.

## 전체 Wikidata 조회로 확인한 확장 후보

이후 Train 7,488종 전체를 정확한 InChIKey로 조회했다. 단일 Wikidata 항목 연결 6,281종 중 한글 또는 영문 위키 문서 후보가 있는 항목은 2,116종이다. 다중 QID 90종은 자동 이름·문서 연결에서 제외했다. 문서 연결 여부를 우선한 새 100종 후보는 `data/wikipedia_document_candidates.csv`에 따로 저장했다. 출처 그룹을 먼저 맞춘 기존 100종을 서비스 전체의 최종 항목 집합으로 고정하지 않는다.

이 조회는 GMS 없이 수행했으며 이름·별칭 매핑은 앱에 연결했다. 위키 본문과 고정 revision은 아직 수집하지 않았으므로 기존 승인 발췌 6종/9건과 구분한다. 상세 집계와 후속 기준은 `03_출처_검토_보고서.md`에 기록했다.

## 문서 범위와 이름 검색 구조 개선

2026-10-22 사용자가 전달한 Claude 대화를 기존 명세서와 체크리스트에 대조했다. 사용자 지적은 전체 항목 수에 비해 문헌 답변이 가능한 항목이 너무 적고, 친숙한 한글·영문 이름으로 검색하기 어렵다는 것이다. 아스피린·카페인 두 사례를 보강한 것만으로 규모 문제를 해결했다고 판단하지 않는다. 다른 팀의 데이터 품질에 대한 대화 속 추정은 확인된 사실로 채택하지 않았다.

## 실제 전체 조회 결과

성공 배치는 `research/provenance/wikidata_batches/`에 응답 해시·조회 시각·질의 해시와 함께 저장했다. 오류가 나면 미조회로 남기고, 부분 결과로 전체 별칭 파일을 덮어쓰지 않는다. 전체 재실행에서는 75개 캐시를 사용해 추가 HTTP 요청 없이 같은 집계를 얻었다.

- 전체 매핑: `data/wikidata_compound_links.jsonl` 및 같은 이름의 CSV
- 집계: `docs/evidence/wikidata_coverage_summary.json`
- 문서 연결 여부를 우선해 선택한 100종 후보: `data/wikipedia_document_candidates.csv`

## 이름 검색에 반영한 내용

단일 식별자 연결의 한·영 이름과 별칭을 공통 검색에 연결했다. 기존에 개별 대조한 별칭도 유지한다. 모호한 90종과 Test 항목에는 이 매핑의 이름을 적용하지 않는다. 앱과 목록은 로컬 파일을 읽으며 사용자의 이름 검색마다 Wikidata나 GMS를 호출하지 않는다.

나이아신아마이드 A-659는 Wikidata Q192423으로 연결되며 영문 문서 Nicotinamide와 한글 문서 니코틴아마이드가 있다. 에탄올 A-356, 글리세롤 A-1896, 아세톤 B-131은 수동 별칭 추가 없이 한글 검색으로 찾도록 연결했다. 부분 검색에는 유도체가 함께 나올 수 있으므로 분석 대상 선택에서는 정확한 이름·별칭 일치를 우선한다.

목록에서 위키 문서 후보가 있는 항목만 볼 수 있고, 선택 항목의 후보 원문 링크와 CSV 목록을 제공한다. 별칭을 조회할 때마다 파일 상태를 검사해 느려지던 부분은 한 번 로드하고 재사용하도록 바꿨다. 실제 목록 로드는 이번 로컬 실행에서 약 0.19초였으며 일반 성능 보장을 의미하지 않는다.

오프라인 AppTest는 목록 선택과 A-659 연결, 영문 정확 별칭 우선, 에탄올·글리세롤·아세톤의 한글 검색, 승인 발췌 6종 필터, CSV 행 수와 마지막 페이지를 확인했다. 증빙은 `docs/evidence/compound_catalog_check.json`이다.

## 후보 확보와 문헌 답변 준비의 차이

새 100종 목록은 출처 그룹 균형보다 문서 연결 여부와 한글 문서 존재 여부를 우선한 수집 후보 목록이다. 아직 본문과 고정 revision을 수집하지 않았으므로 `link_only_pending_fetch`로 표시했다. 기존 승인 문헌 6종/9발췌와 벡터 색인을 바꾸거나, 새 100종이 RAG 답변 준비를 마쳤다고 표시하지 않았다.

다음 단계는 후보마다 문서 본문과 고정 revision, Wikidata 항목 연결, 출처 표시 및 이용 조건을 확보하는 것이다. 식별자·revision·출처·이용 조건 검사는 규칙으로 일괄 처리하고, 모호한 항목과 예외를 따로 검토하는 방향으로 바꾼다. 라이선스 검사가 내용의 과학적 정확성까지 보장하지는 않는다. 그림이나 별도 인용물까지 같은 조건이라고 가정하지 않는다.

UI는 첫 화면에서 가능한 질문과 문헌 준비 범위가 보이도록 개선한다. 화합물의 친숙한 이름·원래 이름·구조·실험값을 함께 보여주고, 문헌 후보와 답변 준비 항목을 구분한다. 로그인이나 장식 기능 추가로 데이터 범위 문제를 가리지 않는다.
