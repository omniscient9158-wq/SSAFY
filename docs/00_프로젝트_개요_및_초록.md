# 프로젝트 개요 및 초록 초안

## 프로젝트명

**화합물 수용해도 근거 탐색: AqSolDB 기반 RAG**

**영문명:** *Evidence-Grounded Aqueous Solubility Explorer with AqSolDB*

**앱 이름:** AqSolDB 화합물 근거 탐색

## 한 문장 소개

AqSolDB 화합물을 선택해 데이터와 출처 확인 문서를 근거로 질문하고, 답변에 실제 사용한 출처를 확인하는 화학 도메인 RAG 서비스.

## 핵심 질문

1. 선택 화합물과 연결된 메타데이터 및 외부 문서를 검색해 근거 있는 답변을 만들 수 있는가?
2. 답변에 실제 사용된 근거만 출처와 함께 표시하고, 근거가 부족하면 확인할 수 없다고 답하는가?
3. 부가적인 LogS 예측과 유사 화합물 비교를 출처·실험값과 혼동 없이 설명할 수 있는가?

## 국문 초록 초안

본 프로젝트는 화합물 탐색을 위한 근거 기반 질의응답(RAG) 서비스를 구현한다. 사용자가 AqSolDB 화합물을 선택하고 질문하면, 항목 메타데이터와 해당 화합물에 연결된 출처 확인 문서를 별도 검색한 뒤 근거를 병합해 답변을 생성한다. 답변은 검색된 내용만 사용하며, 주요 주장에 인용을 표시하고 실제 인용된 출처의 제목·URL을 함께 제공하도록 설계한다. 외부 문서가 다루는 범위와 원출처를 기록해, 단순한 화학 챗봇과 구분되는 데이터 계보 추적을 포함한다. 도메인 특화 보조 기능으로는 AqSolDB의 9개 원자료 통합 데이터와 17개 2D descriptor를 이용한 연속형 LogS 회귀를 둔다. 초기 Ridge 기준선은 train 내부 무작위 검증에서 MAE 1.146, RMSE 1.508, R² 0.593을 기록했다. train 원자료 그룹 A-F를 하나씩 제외한 초기 분석에서는 pooled MAE 1.364, RMSE 2.198, R² 0.141이었으며, 이는 예비 관찰이지 출처가 오차를 일으킨다는 인과적 증거는 아니다. 현재 제공 test 분할은 사용하지 않았으며, RAG 기능의 실행 검증과 답변·인용 품질 평가는 진행 중이다.

## English Abstract (draft)

AqSolDB is used to build a retrieval-augmented question-answering service for compound exploration. After a user selects a compound, the application retrieves its metadata and reviewed external-document passages from separate collections, combines the evidence, and generates an answer grounded only in the retrieved content. Major claims are designed to carry citations, and only cited sources are shown with their titles and original URLs. The project also records the scope and provenance of external passages, making evidence traceability a central part of the chemistry-domain workflow. As a supporting domain feature, a continuous LogS regression baseline uses 17 two-dimensional descriptors from AqSolDB, a dataset curated from nine source datasets [1]. An initial Ridge model achieved an MAE of 1.146, an RMSE of 1.508, and an R² of 0.593 on a random validation split within the training data. In a separate leave-one-source-group-out analysis over groups A–F, pooled performance was MAE 1.364, RMSE 2.198, and R² 0.141. These preliminary results do not establish a causal effect of provenance on prediction error. The provided test split remains untouched; RAG execution and answer/citation quality evaluation are still in progress.

## 초록을 최종화하기 전 확인할 점

- 앱의 검색·인용·예측 흐름이 실제로 구현되고 실행되는지
- 외부 문서 색인에 들어간 각 자료의 원출처와 이용 조건이 기록됐는지
- 모델·분할 설정을 최종 고정한 뒤에만 제공 test.csv를 한 번 평가했는지
- 초록의 숫자와 표현이 최종 코드 실행 결과 및 체크리스트 증거와 일치하는지

## 포트폴리오 차별화 및 검증 계획

“화학 도메인 RAG를 구현했다”만으로는 차별점을 주장하지 않는다. 이 프로젝트에서 보여줄 수 있는 구체적인 강점은 AqSolDB 행과 원자료 계보를 보존하고, 화합물 구조 식별자를 대조한 외부 문서만 사용하며, 답변에 실제 쓰인 인용만 남기는 근거 관리다. 이 설계가 실제로 답변 품질을 개선하는지는 별도로 측정해야 한다.

필수 RAG 기능을 마친 뒤 F2015 실험으로 같은 5개 이상 질문에 대해 검색 없는 답변과 근거 검색 답변을 나란히 기록한다. 질문에는 데이터에 있는 사실 질문, 단위·측정 조건 질문, 출처 질문, 승인 발췌에 없는 질문을 포함한다. 각 답변을 `사실이 근거에 의해 뒷받침되는가`, `인용이 해당 주장과 원문에 맞는가`, `근거가 없을 때 추측하지 않는가`로 판정하고, 불일치 사례와 수정 내용을 함께 남긴다. 결과를 직접 측정하기 전에는 정량적인 개선을 주장하지 않는다. F2014 MMR 비교는 시간이 남을 때 보조 실험으로만 진행한다.
