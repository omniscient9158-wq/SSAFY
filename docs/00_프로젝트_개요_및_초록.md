# 프로젝트 개요

## AqSolDB 화합물 근거 탐색

화합물의 실험 수용해도와 검토된 문헌을 함께 확인하는 RAG 서비스다. 화합물 이름·별칭·ID로 검색하고, 질문에 사용된 근거 번호와 원출처 링크를 확인한다. 문헌 수용해도와 실험 기록을 비교할 때는 단위와 측정 조건을 구분한다.

Train 7,488종을 검색할 수 있으며 메타데이터 100건과 외부 문헌 6종의 발췌 9건을 별도 컬렉션에 색인했다. 화합물별 대화 기록과 수치 조건 검색을 제공하고, LogS 예측은 보조 기능으로 표시한다. 대표 질문 5개로 RAG 전후 답변을 비교해 인용 일치와 부가 설명 오류를 기록했다.

문서 확보 대상 100종 중 94종의 검토는 남아 있다. 현재 근거로 확인되지 않는 값·기전은 답변을 보류한다. 교육용 데이터 탐색을 목적으로 하며 건강·안전·취급 판단을 제공하지 않는다.

상세 요구사항·설계·실행 기록은 [README](../README.md)의 제출 문서 목록을 따른다.
