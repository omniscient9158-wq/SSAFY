# AqSolDB 화합물 근거 탐색

**김지은 · 서울 08반 · 1인 프로젝트**

화합물을 찾아 AqSolDB 실험 기록과 검토된 문헌을 확인하는 RAG 앱입니다. 답변에 사용한 근거 번호와 원출처를 함께 보여줍니다.

## 주요 기능

- 필수: 항목·문헌 컬렉션 분리, 검색어 추출과 후보 선별, 청킹·색인, LangGraph 검색·생성, 인용 표시, 화합물별 대화 기록, 조건 검색, 진행·오류 안내.
- 도메인 기능: 문헌 수용해도와 실험 기록의 단위·측정 조건 비교. LogS 모델 예측과 유사 화합물은 보조 기능입니다.
- 선택 심화 F2015: 대표 질문 5개의 RAG 전후 답변을 비교했습니다.
- F2013·F2014·F2016은 선택 완료로 처리하지 않았습니다.

이름·별칭 검색은 Train 7,488종을 대상으로 합니다. 출처·이용 조건을 검토해 14종·17발췌를 승인했습니다. 기존 Chroma 색인에는 이 중 6종·9발췌가 반영되어 있으며, 추가 승인한 8종은 임베딩을 시도했지만 GMS 사용량 한도로 거절되어 색인되지 않았습니다. 앱의 로컬 문서 검색은 승인 발췌를 대상으로 하고, 의미 검색은 현재 색인된 문서만 대상으로 합니다. 추가 조사 후보 86종은 승인 범위에 포함하지 않습니다.

## 설치와 실행

프로젝트 루트의 PowerShell에서 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
streamlit run app.py
```

로컬 이름·조건·문헌 검색은 GMS 호출 없이 사용할 수 있습니다. 의미 검색과 답변 생성은 `.env`의 `GMS_KEY` 설정이 필요하며, 화면에서 각각 동의한 뒤 호출합니다. 의미 검색을 쓰려면 아래 색인도 준비하세요.

## 데이터 준비와 색인

```powershell
python src/compound_data.py
python src/index_external_documents.py
# 아래 두 명령은 임베딩 API 사용량이 발생합니다.
python src/index_metadata.py --index
python src/index_external_documents.py --index
```

Train 메타데이터 100건과 승인 문헌 17건을 별도 Chroma 컬렉션으로 관리합니다. 현재 보존된 문헌 벡터 색인은 기존 9건입니다. 추가 승인한 8건은 임베딩 요청이 GMS 사용량 한도로 거절되어 색인되지 않았습니다. 사용량이 복구되면 색인 명령을 다시 실행해 승인 문헌 전체를 갱신합니다. 청크 기본값은 1,000자·중복 200자이며 `.env`에서 조정합니다. 화면의 의미 검색 Top-k는 기본 3입니다.

후보 수집은 `src/discover_wikipedia_candidates.py`에서 수행합니다. PubChem 경로는 `--provider pubchem`, Wikipedia 경로는 `WIKIMEDIA_CONTACT` 설정을 사용합니다. 후보 수집에는 GMS·외부 API 호출이 발생하며, 후보는 원문·식별자·이용 조건 검토 후 승인합니다.

## 사용 방법

1. 타우린·카페인·아스피린 등 이름이나 AqSolDB ID를 검색합니다. 새 구조는 SMILES로 입력합니다.
2. 결과 아래에서 질문 예시를 고르고 **근거 검색**을 누릅니다.
3. 발췌와 원출처를 확인한 뒤, 필요하면 동의 후 **근거 기반 답변 생성**을 누릅니다.
4. 분자량·LogP 조건은 사이드바에서 검색합니다. 예: `분자량 300 이하, LogP 2 미만`.

실험값과 예측값은 구분합니다. LogS 눈금은 -10~2의 참고 표시이며 신뢰도나 측정 조건을 뜻하지 않습니다. 문헌에 없는 내용은 확인되지 않았다고 안내합니다.

## 데이터와 이용 조건

- [AqSolDB v1](https://doi.org/10.7910/DVN/OVHAW8): 전체 9,982행. 배포본 라이선스 표기는 CC0 1.0이며 upstream 원자료의 조건까지 같다는 뜻은 아닙니다.
- [AqSolDB 논문](https://www.nature.com/articles/s41597-019-0151-1), [분할 사본](https://huggingface.co/datasets/maomlab/AqSolDB/tree/main/AqSolDB).
- 외부 발췌: NOAA/CAMEO의 NTP 기록과 Wikipedia 등. 원출처·인용 URL·이용 범위를 문서별로 기록했습니다. Wikipedia 요약·번역은 CC BY-SA 4.0 조건을 표시합니다.
- 자세한 내용은 [출처 검토 보고서](docs/03_출처_검토_보고서.md)와 `data/approved_external_sources.csv`에 있습니다.
